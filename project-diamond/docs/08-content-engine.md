# 08 — Content Engine
System: one **daily content spine** → auto-repurposed to every channel. Shoot once (weekly 2-hour block, dusk light), cut many.

## Repurposing pipeline (the machine)
1. **Spine asset** (per day): one core idea + one hero visual (video or still).
2. Auto-derivatives: TikTok (raw cut, native captions) → IG Reel (graded cut + cover frame) → YT Short (retention re-edit, first 2s re-hooked) → Pinterest (still + text overlay, SEO title) → Facebook (Reel + longer caption) → Journal para (SEO) → email snippet → SMS one-liner.
3. Tools: CapCut templates (3 house styles), Canva brand kit (Pinterest), Higgsfield for AI-video days (see doc 09), Buffer/Later for scheduling, Klaviyo for email/SMS.
4. Cadence: 1 spine/day; Tue+Sat are UGC-repost days (rights via comment + DM template); Sunday = community montage.
