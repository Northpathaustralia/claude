# 09 — Higgsfield AI Video System (250 concepts)
Structure: each category has a **Format Spec** defining its default 11 fields (opening frame, camera, scene, lighting, emotion, dialogue, voiceover, captions, music, VFX, ending CTA). Each numbered concept = Format Spec + the listed overrides → a complete, promptable video. Three fully-written exemplars per category show the assembled output.

## Global defaults
Lighting: dusk hour, warm blacks, film grain, practical lamps + steam diffusion. Music: soft analogue ambient, 60–70 BPM, vinyl warmth. Captions: lowercase serif, bone-white, bottom-third, word-by-word reveal. Ending CTA: jar on bath edge, text "the night, reclaimed. — evenfall" + soft logo sting. Aspect 9:16, 15–30s unless noted. VFX: subtle only — steam emphasis, petal float, slow light falloff. No morph gimmicks: premium restraint.
