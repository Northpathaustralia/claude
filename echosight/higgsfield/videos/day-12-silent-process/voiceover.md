# Voiceover — Day 12: The silent process trend, done right

Record dry (phone in quiet room, 20cm from mouth) or generate. Delivery: NO VOICEOVER — ambient kitchen sound only (knife, sizzle, pour). This is the point of the format.



Timing check: read aloud at ~3.8 words/sec; each line must fit its window with ≥0.3s air. If a line runs long, cut words — never speed the read.
