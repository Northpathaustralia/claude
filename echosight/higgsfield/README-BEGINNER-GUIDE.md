## The workflow (per video, ~60–90 min once practised)

1. **Read** concept.md and final-script.md (5 min).
2. **References first:** if this video uses Maya or Danh and you haven't yet, generate the character reference sheet per `../character-continuity.md` (once, reused all month).
3. **Generate shot 1 (the hook) first.** Paste the shot-1 prompt from higgsfield-prompts.md, attach references, generate. Judge it against quality-control.md. Retry with the noted fixes — max 5 attempts (log each in quality-control.md), then either accept or switch that shot to phone footage.
4. **Generate remaining shots** the same way. Download everything into the folder.
5. **Voice:** record voiceover.md on your phone in a quiet room (better) or generate it (faster). Dry, natural pace.
6. **Assemble:** follow edit-decision-list.csv top to bottom in CapCut (free): drop clips, trim to the listed durations, add VO, import captions.srt, add text overlays where the script marks ON-SCREEN.
7. **QC gate:** run the quality-control.md checklist. Score honestly. Below 88/100 = fix or reshoot the failing shot; never ship a failing video because the calendar says so — swap in a carousel day instead.
8. **Export** per platform-exports.md and schedule.

## Golden rules

- Hooks before middles, across all videos — kill weak concepts early.
- 3–5 second generations, fast cuts in the edit. Long takes waste credits.
- Hands are where AI fails: check every frame with hands before accepting a shot.
- The founder is never AI-generated. Days 7/14/27 are phone-camera days — protect them.
