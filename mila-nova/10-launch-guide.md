# 10. Beginner Launch Guide — Zero to Live on Minimal Money

No fluff. Do these in order. Budget assumption: **under $60/month.**

---

## Tools needed (total ≈ $30–60/month)

| Tool | For | Cost |
| --- | --- | --- |
| AI image generator with character-consistency (pick ONE with commercial rights — check its ToS) | All Mila content | ~$10–30/mo |
| Canva (free tier) | Logo, text cards, carousels, watermark | $0 |
| CapCut (free) | Reels/TikToks/slideshows | $0 |
| MailerLite (free tier) | Email list + Free Render Friday | $0 |
| Carrd or GitHub Pages + a domain | Landing page hosting | $0–19/yr + ~$15/yr domain |
| Fanvue account | Subscriptions | $0 upfront (platform takes a revenue cut) |
| Google Drive/Notion (free) | Folders, records, calendar | $0 |
| Buffer/Later free tier (optional) | Scheduling | $0 |

Don't buy anything else until $1k/month. No courses, no "AI influencer
masterclasses," no paid Discords.

## Accounts to create (in this order)

1. New email address just for the brand (this logs into everything).
2. Instagram → TikTok → X — same handle everywhere (`@milanova.ai` pattern, see [01](01-brand-identity.md)); set bios + disclosure immediately, even before content.
3. Domain + landing page host.
4. MailerLite (connect the form).
5. Fanvue — register as an **AI creator** (it has an AI declaration at signup), complete its verification, set profile + disclosure + tiers from [03](03-subscription-tiers.md).
6. Password manager entries for all of it + 2FA on everything. An account takeover ends the business.

## Content workflow (the weekly loop)

**Sunday batch day (2–3 hours):**
1. Check this week's calendar row ([04](04-content-calendar.md)) / weekly engine ([07](07-marketing-strategy.md)).
2. Generate the week's images from [06](06-image-prompts.md) — batch, using the canon-face reference every time.
3. Cull hard: best 20% into `Approved/`, run each through the 60-second gate ([09 section H](09-compliance-checklist.md)), watermark.
4. Assemble reels/slideshows in CapCut; pair with captions from [05](05-promotional-content.md).
5. Schedule the week (or set phone reminders to post manually — manual posting also lets you reply immediately, which the algorithms like).

**Daily (20–30 min):** post/confirm the day's content → reply to comments in voice → send welcome messages to new subs → note anything that popped.

## Daily checklist
- [ ] Today's post is up on the right platform(s), AI label ON
- [ ] Replied to comments (first hour matters most)
- [ ] New subscribers welcomed (AI-disclosed message from [05](05-promotional-content.md))
- [ ] DMs within boundaries — anything weird handled per the rules, screenshots of anything concerning into `05-Records/`
- [ ] One community touch (one genuine comment in an AI-creator community)

## Weekly checklist (Fridays, 30 min)
- [ ] Free Render Friday email sent
- [ ] Fanvue main drop posted + next week's poll queued
- [ ] Numbers into the tracker (see below)
- [ ] Disclosure spot-check on 5 recent posts
- [ ] Next week's batch day planned; any theme-poll winner noted
- [ ] Monthly (first Friday): platform-policy re-check + canon-face reverse-image re-check, both logged

## How to test content

- Weeks 1–4: post the calendar as written — it's deliberately varied (comedy / glam / interactive / diary). That variety IS the test.
- Track per post: reach, saves (IG), watch-through (TikTok), profile taps, link clicks.
- After 30 days, rank everything. The top format gets made 2× as often next month; the bottom format gets one more chance with a better hook, then dies.
- Test ONE thing at a time (hook vs. visual vs. caption), or you learn nothing.
- Poll participation is the retention metric that matters most on Fanvue — if it drops, the product is drifting.

## How to track revenue (one spreadsheet, five columns)

`Week | Subscribers (by tier) | New | Cancelled | Revenue`

Plus one row of notes: what you changed that week. Review every Friday.
Rule of thumb: churn above ~25%/month means a content/expectation problem —
fix delivery cadence and poll engagement before chasing new fans. Keep
platform payout statements in `06-Business/` for tax. Get an accountant
involved at ~$1k/month (ABN, GST threshold awareness, income declaration).

## How to avoid getting banned (the short version)

1. Disclose AI everywhere, always — it's the rule on Fanvue and increasingly everywhere, and it's also your brand.
2. Assume the strictest platform's rules apply to all content (that's TikTok).
3. Never imply explicit content exists. Not even as a joke.
4. Never touch real-person likenesses, in either direction — inputs or outputs.
5. No mass DMs, no link-spam, no bought followers, no engagement pods.
6. Read community rules before posting in any community.
7. Keep the email list growing so a ban is a bruise, not a funeral.
8. When a platform warns you — comply instantly, log it, don't argue with the moderation bot.

## What to do first, second, third, fourth

**FIRST (days 1–3): identity.**
Read [01](01-brand-identity.md) + [09](09-compliance-checklist.md). Create
accounts + bios with disclosure. Generate the canon face (prompt #35),
reverse-image-check it, lock it, save records.

**SECOND (days 4–7): assets.**
Generate the week-1 and week-2 images from [06](06-image-prompts.md). Make the
Canva wordmark + watermark. Put the landing page live (host
[landing-page/index.html](landing-page/index.html), connect MailerLite, link
Terms/Privacy/Refund pages). Set up the Fanvue profile and tiers — leave it
unlaunched but stocked with 5 posts.

**THIRD (days 8–37): the 30-day calendar.**
Run [04](04-content-calendar.md) exactly as written. Daily checklist daily,
weekly checklist Fridays. Fan club doors open on Day 22 as scripted.

**FOURTH (day 38+): the engine.**
Switch to the weekly engine in [07](07-marketing-strategy.md). Review the
30-day data, double the winning format, start the first-100-fans levers, and
run the monthly compliance re-checks forever.

That's the whole game: a consistent character, a weekly promise you keep,
compliance you never bend, and a spreadsheet you look at every Friday.
