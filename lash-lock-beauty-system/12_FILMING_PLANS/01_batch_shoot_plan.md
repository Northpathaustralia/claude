# 12 · One-Day Batch Shoot Plan (30+ days of content)

**Goal:** in a single day, capture the full mini-course **plus** the master footage for weeks of organic reels and ads. Real-footage-first.

## Equipment checklist (affordable)
- Recent iPhone (main cam) · [optional] second phone for split-face second angle
- Sturdy tripod + a top-down/overhead phone mount
- Small clamp/mini-mount for macro angle
- Wireless lav mic (e.g. budget wireless mic) — **test levels first**
- Window light + one soft LED panel (key), white foam board / A3 card (reflector/fill)
- Clean neutral backdrop (oat/cream wall or fabric)
- Existing makeup station + the 8 essentials + Lash Lock (cleaned) + tissues
- Macro clip-on lens **only if pre-tested sharp**
- Editing: CapCut / Canva
- Backup: cloud + one physical drive

## Room & lighting (in words)
Face the window. Key = window or LED at 45°, just above eye line. Reflector on the opposite side to lift shadows. For macro/demo, add even fill so fallout/texture reads truthfully (don't hide proof). One colour temperature only (~5000K) — no mixed warm/cool in frame.

## Camera settings
- 4K, 30fps (or 60fps for slow-mo fallout drops); lock exposure & focus per setup.
- Vertical 9:16 primary; also grab a few 16:9 if the course host prefers wide.
- Gridlines on; keep eye in the upper-middle third; leave safe margins for captions.

## Continuity (lock for the whole day)
One outfit, one makeup look, same nails/jewellery, same set dressing, same products. Shoot continuity reference photos of: full set, product layout, Kat's seat mark, macro mount height.

## Audio setup
Lav on, quiet room, soft furnishings; record a 10s room-tone; monitor with earbuds; clap once at each take start for sync.

## Shot order (efficient — group by setup, not by lesson)
**Block A — Set 1 talking-head (mic on):** all intros/outros + Lesson 0 + all spoken-to-camera pieces + hook deliveries for organic reels.
**Block B — Set 1 over-shoulder demos:** Lessons 2,3,4,5,6 application in sequence on one continuous look (so continuity holds). Capture the Lesson-8 real-time run here.
**Block C — Macro inserts:** press-vs-swipe, tap-off, the **catch reveal** (Lesson 4 — shoot many takes), backstop, rescue. This is your most reused footage — over-shoot it.
**Block D — Split-face proof:** messy side vs clean side for the "Clean or Messy?" series (organic hero).
**Block E — Set 2 flat-lay:** tool list, product drops, packaging (real Lash Lock).
**Block F — Set 3 lifestyle B-roll:** getting-ready, vanity, morning light (also AI-augmentable later).
**Block G — Heat check:** schedule for end of a real day out (separate session) — film the honest longevity result.

## File naming
`LLBS_[block]_[lesson-or-asset]_[take].mp4` → e.g. `LLBS_C_L4catch_07.mp4`. Log keepers in a shot sheet.
