## 1. Clean Eye Method Card (one-page, print-for-mirror) — also the free lead magnet
**THE CLEAN METHOD — P·B·C·A·S**
1. **PREP** — Moisturise, wait 60s. Press (don't swipe) concealer. **Set before shadow.**
2. **BASE** — Thin lid base, whisper of powder. *Tiny.*
3. **CONTROL** — Hold your fallout tool under the lash line like a shelf. Apply, then lift. No cleanup.
4. **APPLY** — 3 shades: transition (crease), lid (pat), outer corner (shape). *Tap off. Pat, don't sweep.*
5. **SET & FINISH** — Liner: dot → connect. Mascara: tool as backstop. Set lightly. Done.
> *Tap off · Press don't swipe · Set before shadow · Control the fallout.*

## 3. Eye-Shape Observation Guide
Look in the mirror, relaxed, eyes open:
- **Crease visible?** → standard placement works.
- **Hood covers crease?** → place transition slightly *above* your natural crease so it shows with eyes open; keep base sheer.
- **Downturned outer corner?** → lift the outer shade & liner slightly up.
- **Mature/fine lines?** → less powder, press don't pack, sheer base, matte-leaning shades.
- **Oily lids?** → primer over concealer-base; extra light set.
- **Close-set / wide-set?** → concentrate depth outer (close-set) or blend more evenly (wide-set).
*Rule: work with what your eye does when it's open, not closed.*

## 4. Fallout Prevention Checklist
☐ Set under-eye concealer **before** shadow
☐ Base the lid (grip = less drop)
☐ Load brush **light**, tap off excess
☐ **Pat** lid colour, don't sweep
☐ Hold the control tool under the lash line while packing
☐ Do darkest/glitteriest shades last, over the tool
☐ Never wipe fallout wet — sweep dry or lift, then press-touch-up

## 6. Troubleshooting Guide
| Problem | Cause | Fix |
|---|---|---|
| Cakey under-eye | Too much / wet base / swiped | Less, wait, press, set |
| Fallout on face | No set / heavy hand / no control tool | Set first, tap off, hold tool |
| Shadow creases by lunch | No lid base / too much base | Thin base + whisper powder |
| Uneven liner | Freehand long line | Dot → connect; match to lower lash line |
| Lid print from mascara | No backstop | Hold tool behind lashes |
| Muddy colour | Too many shades / dirty brush | 3 shades, wipe brush between |
| Looks patchy on camera | Under-blended / flash on shimmer | Blend edge, matte-lean for photos |
