# 22 · JAMES AND KAT'S DUMB-DOWN ACTION PLAN

Plain language. Do the stages in order. Nothing risky ships until Stage 1 is done.

## Stage 1 — Confirm the product (do this FIRST)
- **Test:** run every test in `04_PRODUCT_VERIFICATION` on the real Lash Lock (fallout, under-eye protection, mascara, liner, cleanup, comfort, durability, on hooded/mature/oily eyes).
- **Photograph:** front/back/side/scale/colour/logo/packaging + the "catch" happening.
- **Verify claims:** only claims that pass become sayable. Everything else stays out.
- **Get from supplier:** material, latex-free?, cleaning method, reuse lifespan, country of origin.
- **Answer customer Qs:** does it work on my eyes? how do I clean it? is it safe near eyes? how long does it last?
- **Book:** a qualified AU adviser to check final claims + refund/guarantee wording.

## Stage 2 — Set up Kat's filming identity
- **Photos:** well-lit front + 3/4 face; hair; signature makeup; wardrobe; nails; jewellery → save in `refs/`.
- **Voice:** record 3 takes (calm / friendly / promo) of a test script on your phone in a quiet soft room.
- **Wardrobe:** one outfit in oat/clay/cream for the whole batch.
- **Set:** pick your beauty station (Set 1) + a clean table (Set 2) + a bright vanity (Set 3).
- **Continuity:** take reference photos of each set so you can rebuild it.

## Stage 3 — Film the real demonstrations
Follow `12_FILMING_PLANS` shot order: Block A talking-head/hooks → B demos → **C macro (over-shoot the catch)** → D split-face → E flat-lay → F lifestyle. Schedule the heat-check (Block G) for a real day out. Back up footage twice.

## Stage 4 — Build the mini-course
1. Edit the 8 lessons from footage (`07_LESSON_SCRIPTS`).
2. Add step-tags/captions (`14_EDITING_SYSTEM`).
3. Make the 10 downloadables in Canva (`08_DOWNLOADABLES`).
4. Upload lessons + downloads to your host; set the $27 price, $14 bump, $69 upsell.
5. **Test access yourself** (buy it, watch it, download everything) before anyone else.

## Stage 5 — Make the Higgsfield assets (B-roll only)
For each AI shot (`11_HIGGSFIELD_PROMPTS`): upload the real reference → pick the model (test a cheap clip first) → paste the ready prompt → set 9:16 + duration → **inspect** (geometry, logo, no bad hands, no flicker) → regenerate if it drifts → **if it still looks off, film it for real instead.** Keep AI to product/lifestyle/transition only.

## Stage 6 — Build the sales page
Follow `15_LANDING_PAGE` order exactly: announcement bar → hero → demo video → problem → outcome → inclusions → lessons → who it's for/not → Kat authority → Lash Lock (honest) → proof (real only) → FAQ → guarantee (approved) → final CTA → disclaimers. Then checkout + bump + upsell.

## Stage 7 — Prepare launch content
Publish calendar Wk1–3 first (warm-up/educate/proof). Put the free Method Card everywhere to build the email list. Schedule the week with the Sunday batch-edit routine.

## Stage 8 — Soft launch
Open to your email list + engaged followers only. Watch them buy, access, and use it. Fix any funnel friction. Collect the first **real, consented** testimonials/results. Adjust the promise if anything under-delivers.

## Stage 9 — Public launch (7 days)
Run calendar Wk4 + email sequence D. Any deadline must be real. Post daily, reply for the first hour, and track add-to-cart, conversion, refunds.

## Stage 10 — Improve
Every Friday, read the dashboard: keep winners, change hooks on low-hold pieces, recut low-completion ones, retire losers. Once you have 2 organic winners and know your margins, start small paid tests. Build the bundle/add-on/flagship from what's working.
