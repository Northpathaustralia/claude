# 30 · Launch-Day Checklist, Incident, Defect & Recall Procedures

## Launch-day checklist (run in order)
**Pre-open (T-1 day)**
☐ Test purchase end-to-end (buy → pay → webhook → access → downloads → emails) ☐ Refund path tested ☐ All links live + mobile-checked ☐ Claims match register (no ❌/⚠️) ☐ Analytics + consented pixels firing ☐ Support inbox monitored ☐ Backups current ☐ Stock/fulfilment ready (bundle) or bundle hidden until verified.
**Open (T-0)**
☐ Flip product live ☐ Send launch email L2 ☐ Post launch reel ☐ Watch first 5 orders complete fully ☐ Reply to comments/DMs first hour.
**During (7 days)**
☐ Daily: post + reply + log metrics ☐ Watch add-to-cart→purchase + refund rate ☐ Any funnel break → fix fast.
**Close**
☐ Honest close (real deadline only) ☐ Thank buyers ☐ Post-launch review.

## Incident procedure (customer harm / safety)
1. Acknowledge + advise stop use.
2. Log: `30_incident_log` (who/what/when/severity/photos if provided).
3. Assess: isolated or pattern? 4. If safety pattern → **pause product sales**, investigate with supplier, consider recall. 5. Refund/replace affected customers. 6. Review affected claims. 7. Post-incident note.

## Product-defect process
Report → verify (photo/return) → replace/refund → log SKU/batch → if batch pattern, quarantine stock + raise with supplier (batch ID) → update QC.

## Recall (draft procedure — hopefully never)
1. Decide scope (batch/all) with advice. 2. Stop sales + shipments. 3. Notify buyers directly (email/SMS) with reason + remedy (refund/replace) + safety instruction. 4. Notify authorities if required (ACCC product safety). 5. Track returns/remedies. 6. Root-cause + corrective action with supplier. 7. Public notice if required.
**Recall notice template:** "Important safety notice about Lash Lock (batch {x}). Please stop using it and {action}. We'll {refund/replace}. Contact {…}. We're sorry."

## Logs to keep
Incident log · defect log · refund log · recall register — secure drive, not repo.
