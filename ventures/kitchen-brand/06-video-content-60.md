# 11. 60 Short-Form Video Concepts (Lola & Mia)

**Global production notes (apply to every video):**
- **Format:** 9:16 vertical, captions always on, hook lands inside 1.5 seconds, product
  visible by second 3, one idea per video.
- **Compliance (all videos):** photorealistic AI-generated people → toggle the platform's
  AI-generated/synthetic-media label (TikTok "AI-generated content" toggle, Meta "AI info"
  disclosure on ads). No health/weight-loss claims, no "sale ends tonight" false urgency,
  no competitor names, no knife-glorification framing (sharpener = "restore/maintain").
  Music: use each platform's commercial library for anything that might become an ad.
- **Voice rule:** Lola opens/hooks, Mia proves/closes, synchronized wink to end brand videos.
- **Paid-ready (💰)** = shoot a clean version without trending audio so it can run as an ad.

Legend: `L:` Lola line · `M:` Mia line · `[…]` visual direction.

## Production cadence
- Batch-produce weekly: 1 shoot day (or AI-generation day) = 8–12 videos.
- Mix per week: 3 demos · 2 hacks · 2 banter/trend · 1 satisfying · 1 gift/bundle (rotate).
- Every 💰 concept gets a clean no-trend-audio cut exported for the ads library.
- Post natively per platform (no watermarks crossing platforms — TikTok watermark on
  Reels suppresses reach).
