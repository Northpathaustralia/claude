# ATLAS ONE — Owner's Guide (for James)

Plain English, no jargon. Ten minutes to a working AI operating partner.

## 1. Open ATLAS ONE (pick one)

**Easiest — one file, no internet needed after download:**
1. On GitHub, open the file `release/ATLAS-ONE.html`.
2. Click the **Download raw file** button (top right of the file view).
3. Save it somewhere easy — your Desktop is perfect.
4. **Double-click it.** ATLAS ONE opens in your browser. Done.

**Or the web version:** if GitHub Pages is enabled for this repository, the same app is available at your Pages address (Settings → Pages in GitHub shows the link).

> Always use the **same computer and same browser** (e.g. always Chrome) — that's where your data lives. Chrome or Edge give you everything including voice.

## 2. Wake Atlas up (connect an AI provider — about 2 minutes)

Without this step Atlas can only show labelled demonstrations. With it, every conversation is real.

1. In ATLAS ONE, click **Settings** in the left menu.
2. Find **AI Providers** → the **Anthropic (Claude)** row (recommended).
3. Click **Get a key ↗**. A new tab opens on Anthropic's website.
4. Sign up or log in there, add a small amount of credit (US$5–10 is plenty to start), and create an **API key**. Copy it.
5. Back in ATLAS ONE, paste the key into the Anthropic field and click **Save**, then click **Test**.
6. Wait for the green message: **“Connected — the key works.”** That's it.

Your key is stored only in your browser on your computer. Don't use ATLAS ONE on a shared or public computer, and treat backup files like keys.

## 3. Five things to try first

1. **Home** — your briefing: real NorthPath leads, tasks and appointments, plus today's priorities. Click 🔊 to hear it.
2. **Chat** — ask anything. Try the mode buttons: **Smart** for daily work, **Deep Think** for a decision, **X10** for the big stuff (it convenes your specialist council and you can read each specialist's take).
3. **Say “Remember that I prefer short answers.”** Atlas confirms, and you can see/edit/delete everything it knows in **Memory**.
4. **AI Studio** — pick *Presentation*, write one sentence about a business idea, click **Create**, then download the result.
5. **Business Centre** — your NorthPath numbers live; click **Open workspace** for leads, content, referrals and reports.

## 4. Everyday habits

- **Weekly backup:** Settings → **Export full backup**. Keep the file somewhere safe (it includes your keys — treat it like a password).
- **Upload documents** in **Knowledge** (.txt, .md, .csv…) and Atlas will use and cite them. PDFs aren't supported *yet* — copy the text into a .txt file for now.
- **Projects:** create one per venture, write instructions once ("use AUD, metric, assume 24/7 gym"), attach conversations to it — Atlas follows those instructions every time.
- **Voice:** the 🎙️ button is push-to-talk — it only listens while red and pulsing. "Read replies aloud" is the checkbox under the message box.
- **Stop anything:** the red ■ Stop button halts Atlas mid-answer (and mid-speech) instantly.

## 5. Honesty labels you'll see

**Working** = real and tested · **Beta** = real but young (voice) · **Demonstration** = clearly-labelled sample because no provider is connected · **Planned** = on the roadmap, not pretending. If something ever looks like data but isn't real, that's a bug — nothing in ATLAS ONE is allowed to fake it.

## 6. If something goes wrong

- **“No AI provider connected”** → Step 2 above.
- **Key test fails** → re-copy the whole key (they're long), check your provider credit balance, try again.
- **Voice button missing** → your browser doesn't support it; use Chrome or Edge.
- **Data looks empty** → you're probably in a different browser or computer profile; open the one you set up, or import your latest backup (Settings → Import backup).
