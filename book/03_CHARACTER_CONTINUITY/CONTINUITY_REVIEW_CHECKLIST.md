# Replacement Illustration Review Checklist
Use this on EVERY candidate image for pages 23–30 before it moves from
`05_GENERATED_ART_TO_REVIEW` to `06_APPROVED_REPLACEMENT_ART`. Answer
every line. Any single "NO" means the image goes back for regeneration
— do not approve a page with an open "NO."

## Character identity
- [ ] Pip is clearly the same small brown echidna (not a dog, human,
      mouse, wallaby, teddy-bear, or any other creature)
- [ ] Pip has the large round warm-brown expressive eyes
- [ ] Pip has the long smooth brown-black snout (not spiny, not short)
- [ ] Pip's spines are golden-tan fading to brown, on head/back only
- [ ] Birdie is clearly the same small blue bird (not a kookaburra,
      owl, cockatoo, or any other bird)
- [ ] Birdie has soft dusty sky-blue plumage and a pale cream chest
- [ ] Birdie is small — sized to fit on a branch, roughly Pip's
      head-size

## Consistency
- [ ] Character size relationships match the approved pages (Pip
      small, Birdie tiny, in correct relative scale to each other)
- [ ] Character colours match exactly (no colour drift)
- [ ] Facial features match (eye shape, size, expression style)
- [ ] Pip's backpack is solid opaque teal-blue with the gold buckle
      button
- [ ] Birdie's backpack (if visible in the scene) is the pale
      translucent outline style, not a solid colour

## Style
- [ ] Watercolour style matches the approved pages (soft edges, visible
      paper texture, gentle natural colour, hand-painted feel)
- [ ] Background/environment style (gum trees, wattle, dirt path,
      rounded hills) matches the rest of the book
- [ ] Lighting is warm and soft, matching the book's gentle tone
- [ ] Emotional expression on each character matches what the page
      text describes

## Technical / print
- [ ] Page has enough clear, uncluttered space where the text block
      will sit (per the brief for that page)
- [ ] Nothing important (faces, hands, key story details) sits within
      the outer safe margin (see dimensions note in each brief)
- [ ] No story text, letters, or words are rendered inside the
      illustration itself
- [ ] No spelling/lettering artifacts anywhere in the image
- [ ] No incorrect/unrequested character appears in the scene
- [ ] No clothing appears on any animal unless already established
      (Pip's backpack is the only "clothing" in this book)
- [ ] No modern objects appear (no phones, cars, houses, signage) unless
      the brief specifically calls for one
- [ ] Image resolution is sharp and high enough for print (see
      resolution note in each brief — flag if it looks soft/blurry)

## Continuity with neighbouring pages
- [ ] Environment logically continues from the page before
- [ ] Environment logically leads into the page after
- [ ] No previously-established story detail has been contradicted
