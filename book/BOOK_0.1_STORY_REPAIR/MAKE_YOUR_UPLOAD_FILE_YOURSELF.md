# How to Make Your Upload File Yourself (you have all 40 pictures)

You don't need to send anything to anyone. Your 40 page pictures are on
your device — these tools turn them into the file Amazon wants.

═══════════════════════════════════════════
FASTEST WIN: KINDLE eBook (do this first)
═══════════════════════════════════════════
Kindle Create builds the upload file FOR you from your images. No PDF
needed.

1. Download **Kindle Create** (free):
   https://www.amazon.com/Kindle-Create/b?node=18292298011
   (or search "Kindle Create download")
2. Open it → choose **"Get started"** → pick **"Children's book / Comic"**
   (this makes a fixed-layout picture book).
3. When it asks for pages, select your **40 images in order** (01–40).
   It places one image per page.
4. Click through **Preview** — check every page looks right on the
   phone/tablet views.
5. Fill in **Title** (The Invisible Backpack), **Subtitle**, **Author**
   (James Forycki).
6. Click **Save** (this makes your editable .kcb file) then **Publish /
   Export** — that produces a **.kpf** file.
7. That .kpf is what you upload to KDP. Done.

═══════════════════════════════════════════
PAPERBACK (a printed book)
═══════════════════════════════════════════
This needs one PDF of all 40 pages. Two ways:

**Way 1 — let me build it (best quality):**
Put your 40 original images in one ZIP, attach the ZIP in our chat, and
I'll build the print-ready paperback PDF + cover for you.

**Way 2 — do it yourself in Canva (free):**
1. Go to https://www.canva.com → Create a design → Custom size →
   **11 in × 8.5 in** (landscape).
2. Add 40 pages. Drag one image onto each page so it fills the whole
   page (edge to edge).
3. Keep them in order 1–40.
4. Share → Download → **PDF Print** → tick "crop marks and bleed" OFF
   for now → Download.
5. That PDF is your paperback interior.

═══════════════════════════════════════════
THE 3 WORD FIXES (before you build either file)
═══════════════════════════════════════════
Make sure these are corrected in your images first:
- Page 2: "First edition • 2026" (not "Prototype edition")
- Page 13: "Kangaroo's backpack **seemed** light."
- Page 14: "Birdie's backpack **seemed** tiny."
- Page 40: "Everyone carries something. No one should have to carry it
  alone."

═══════════════════════════════════════════
THEN UPLOAD (kdp.amazon.com)
═══════════════════════════════════════════
1. kdp.amazon.com → sign in → Create.
2. Kindle eBook → upload your .kpf + cover image → set price $3.99 → Publish.
3. (Optional) Paperback → Premium Colour, landscape 11×8.5, upload the
   PDF interior + a cover → order a proof copy → Publish.

Your book description, keywords and categories are ready in
`BOOK_0.1_METADATA_AND_FRONT_BACK_MATTER.md` — copy and paste them in.
