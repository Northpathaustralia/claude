## Beginner instructions to finish this yourself (about 15 minutes)

1. Download and install **Kindle Create** (free, from Amazon):
   https://kdp.amazon.com/en_US/help/topic/G202131170 — search "Kindle
   Create download" on the KDP help site if that link ever moves.
2. Open Kindle Create and choose **"Children's book"** as the project
   type (this keeps it as a fixed-layout picture book, not reflowable
   text).
3. When asked to import pages, select all 32 files in
   `04_KINDLE_SOURCE/` in order (`ebook_001.jpg` → `ebook_032.jpg`).
   Kindle Create will keep them in the order you select them, so select
   them in filename order.
4. Use Kindle Create's **Preview** panel to page through all 32 pages
   on the phone and tablet preview modes.
5. Enter the book title, subtitle, and author (James Forycki) in the
   project details panel.
6. Save the project — this creates the `.kcb` file, which is your
   editable source if you need to make changes later.
7. Use **File → Export** (or the "Publish" build step inside Kindle
   Create) to generate the `.kpf` file — this is the file you actually
   upload to KDP.
8. Upload the `.kpf` to your KDP Kindle eBook listing.

Do not skip step 4 — always look at every page in the previewer before
exporting, since text position can shift slightly when Kindle Create
repackages the file.
