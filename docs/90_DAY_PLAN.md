# 90-DAY LAUNCH PLAN — TIDESTATE

Day 1 = the day James commits to the project full-time. Every phase ends with a go/no-go
gate. KPIs at the end of the document.

## PHASE 1 — BRAND VALIDATION (Days 1–14)

| Day | Actions |
|---|---|
| 1 | Set up project HQ (Notion/Drive), open dedicated bank sub-account, define budget ceiling ($10k Model 1 path). Start filming everything (Engine One begins today). |
| 2 | Review NAME_OPTIONS.md; shortlist 3 names. Run IP Australia TM headline search on each (classes 25/35); check domains + handles for all 3. |
| 3 | Brief trademark attorney for clearance on #1 pick. Buy domains/handles for top 2 defensively (~$100). |
| 4–5 | Customer interviews ×10 (gym friends, café strangers, DMs): "what do you wear from training to dinner?" Record patterns, not compliments. Post first founder video: "I'm building a clothing company. Here's the problem." |
| 6–7 | Competitor deep-dive (COMPETITOR_AUDIT.md refresh): screenshot pricing, drops, mechanics of 5 brands. Mood boards in Figma/Canva (coastal infrastructure, tide data, transit graphics). |
| 8–9 | Name-test content: post 2–3 candidate names/stories to socials + 20 DMs. Watch which one people *repeat back*. |
| 10 | ABN registration; business name reserved once attorney gives preliminary OK. |
| 11–12 | Lock palette + typography; draft wordmark, monogram, breakline icon (assets in this repo are the starting point). |
| 13 | Set up Shopify trial + Klaviyo free tier; landing page with VIP email capture ("First 500 get first access"). |
| 14 | **GATE 1:** name cleared (preliminary), 100+ VIP emails or 2k+ organic views on build content, budget confirmed. If name fails clearance → switch to backup, repeat days 2–3 (built into buffer). |

## PHASE 2 — PRODUCT (Days 15–35)

| Day | Actions |
|---|---|
| 15–16 | Issue MANUFACTURING_BRIEF.md excerpts to 3 local decorators (Model 1) + 5 small-batch factories (Model 2 pipeline). Order AS Colour-tier blank samples in 3 weights. |
| 17–18 | Fabric evaluation on camera: GSM scale, stretch, hold, see-through test. Community votes on Washed Ink shade. |
| 19–21 | Finalise DROP 001 artwork (tee back graphic, cap icon, jersey livery). Legal sanity pass: nothing resembling existing marks/kits. |
| 22–24 | First print/embroidery tests with local decorator. Film every fail. |
| 25–27 | Fit testing on 5 real bodies (XS-friend to XXL-friend); film measurement process; record height/weight/size data for the fit tool. |
| 28–30 | Wash testing: 3 cycles, measure, film. Iterate neck/label positions. |
| 31–33 | Costing locked for Model 1 run; Model 2 quotes compared (landed cost sheet). Place Model 1 production order (tee ×100, hoodie ×50, cap ×75). |
| 34–35 | **GATE 2:** samples pass wash + fit, unit costs within 10% of UNIT_ECONOMICS.md targets, 300+ VIP list. |

## PHASE 3 — BUILD THE MACHINE (Days 36–55)

| Day | Actions |
|---|---|
| 36–40 | Website build-out on Shopify using SHOPIFY_HANDOFF.md (this repo's prototype is the design spec). Product photography plan: golden-hour GC locations list. |
| 41–43 | Photography + video day 1: products on 5 bodies, sunrise-to-night "Uniform" shoot (phone + one hired shooter if budget allows). |
| 44–46 | Build email flows (EMAIL_AND_SMS.md): welcome, founder story, abandonment, post-purchase. Load 20 pieces of founder content into schedule. |
| 47–49 | STATE CREW recruitment: shortlist 30 GC/BNE micro-creators, send 15 application invites; seed 10 caps from sample run. |
| 50–52 | Fit guide + fit videos edited and loaded; measurement charts on every PDP; QR passport pages live. |
| 53–55 | **GATE 3:** site test-ordered end-to-end (real card, real refund), 800+ VIP list, 10 creators confirmed, all DROP 001 stock ETA confirmed in writing. |

## PHASE 4 — PRE-LAUNCH (Days 56–70)

| Day | Actions |
|---|---|
| 56–58 | Product reveal week: one product per day across socials + email (5 reveals). |
| 59–61 | Creator seeding packages ship (numbered caps + tee). Brief per CREATOR_PROGRAM.md — content lands days 64–70. |
| 62–64 | VIP early access opens (48h window, honest stock counts). Pre-orders only where delivery date is confirmed; date stated on PDP and in checkout. |
| 65–67 | Process VIP orders; film packing of first orders; publish "first 100 orders" content. Fix anything the VIP wave breaks. |
| 68–70 | Launch countdown (real timer to a real event — public launch datetime). Paid ads warm-up: $10–20/day engagement campaigns on best organic clips. |

## PHASE 5 — LAUNCH (Days 71–90)

| Day | Actions |
|---|---|
| 71 | **PUBLIC LAUNCH.** Founder live video morning-of. All flows on. Ads to $30/day structure (PAID_AD_PLAN.md). |
| 72–75 | Repost every customer story/photo (ask permission). Daily founder recap videos. Ship same-day where possible; film it. |
| 76–80 | First creative test round read-out; kill losers, scale winners to $75/day if guardrails pass. First Light Club event #1 announced (sunrise walk + coffee, GC). |
| 81–84 | Retargeting layer on; email flow #2 (product education) to non-buyers. Restock survey to buyers ("what next?"). |
| 85–88 | First Light Club event #1 held + filmed. Model 2 production decision using real sell-through data. |
| 89–90 | 90-day retro published (revenue, mistakes, next drop). **GATE 4:** proceed to Model 2 / Drop 002 if Expected targets ~met. |

**Weekly rhythm throughout:** Mon plan + content batch · Tue–Thu ship/film/build ·
Fri numbers review (CAC, sell-through, cash) · Sat community/event · Sun off (seriously).
